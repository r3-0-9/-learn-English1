# Quick English / 快速学英语
一个简洁、互动、高效的中英对照英语学习网站，通过闪卡、测验和每日一句帮助你轻松记忆英语。

A clean, interactive, bilingual English learning website that helps users memorize English efficiently through flashcards, quizzes, and daily sentences.

🌟 功能特色 / Features
功能	说明
📚 单词闪卡 / Flashcards	点击翻转卡片，查看中文释义、英文定义和例句。
🎯 快速测验 / Quick Quiz	5 道英语俚语选择题，即时反馈评分。
📅 每日一句 / Daily Sentence	中英对照名言警句，附语法标签和重点词汇解析。
📱 响应式设计 / Responsive	完美适配手机、平板和电脑。
🎨 精美动画 / Smooth Animations	卡片翻转、淡入淡出等流畅过渡效果。
🚀 在线演示 / Live Demo

📦 本地运行 / Local Development
无需任何构建工具，直接用浏览器打开即可。

No build tools required — just open it in your browser.

方式一：直接双击 index.html
方式二：使用本地服务器（推荐）
bash
# 克隆仓库 / Clone the repository
git clone https://github.com/r3-0-9/-learn-English1.git

# 进入项目目录 / Enter the project directory
cd -learn-English1

# 启动本地服务器 / Start a local server
python3 -m http.server 8000
然后访问：http://localhost:8000

Then visit: http://localhost:8000

🌐 部署到 GitHub Pages / Deploy to GitHub Pages

Create a new public repository on GitHub.

上传代码 / Upload Code
将 index.html、css/style.css、js/app.js 上传到仓库。
Upload index.html, css/style.css, js/app.js to the repository.

进入 Settings → Pages，Source 选择 main 分支，/(root) 文件夹。
Go to Settings → Pages, set Source to the main branch, /(root) folder.

访问网站 / Visit Website

💡 学习小贴士 / Learning Tips
⏰ 每天坚持 15 分钟，进步看得见！/ Stick to 15 minutes a day — you'll see the progress!

🔄 每天复习闪卡，建立长期记忆。/ Review flashcards daily to build long-term memory.

🎯 完成测验后立即查看解析，理解比记忆更重要。/ Check explanations right after quizzes — understanding beats memorization.

📝 把每日一句抄写下来，大声朗读。/ Write down the daily sentence and read it aloud.

🎧 结合听力练习，效果更佳。/ Combine with listening practice for better results.
